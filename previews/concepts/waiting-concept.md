# Nazar waiting animation

The original six-pose concept is in [waiting-concept.png](waiting-concept.png). The implementation uses the current registered Nazar poses. The concentric eye lifts as the flippers rise, holds for two frames, and returns to center. The shell, feet, flippers, alpha, and frame holds are preserved.
